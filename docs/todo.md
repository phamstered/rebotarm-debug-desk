| 项目 | URDF 定义 |

URDF 注释注明安装外参来自 MoveIt 手眼标定；本次只核对了文件定义，尚未验证实机标定精度或 Jetson 正在使用的版本。相机和 `gripper_link` 是 `link6` 下的两个分支，夹爪开合不参与相机位姿计算。该 URDF 的 `camera_link` 只有惯性定义，没有相机外观几何。

```text
base_link
  └─ joint1…joint6 → link6
      ├─ camera_mount_joint → camera_link
      │   └─ RealSense 驱动提供的光学坐标系
      └─ gripper_joint → gripper_link
```

光学坐标系未写在这份 URDF 中，注释约定由 RealSense 驱动发布。实现时以图像实际 `header.frame_id` 为准，核对完整 TF 链，不硬编码光学 frame 名称或猜测轴向旋转。

### 计划数据路径

```text
Jetson：RGB + 对齐到 RGB 的 Depth + 匹配的 CameraInfo
  → 时间配对、预览降采样
  → 按图像采集时刻查询 base_link ← 图像光学坐标系的 TF
  → 配对图像、相机内参和对应位姿经 Bridge 二进制流 / SSH 隧道发送
Mac：深度反投影 → RGB 着色 → 变换到 base_link → Three.js 点云图层
```

深度点先还原到相机光学坐标系，再通过图像时刻的变换进入基座坐标系：

```text
p_base = T_base_link6(t) × T_link6_camera × T_camera_optical × p_optical
```

`t` 对应图像采集时间。机械臂运动时，直接使用最新关节位置会造成环境点云错位；计划由 Jetson 的 TF 缓冲处理时间关联，前端接收与帧绑定的最终变换，不维护另一份手眼外参。
